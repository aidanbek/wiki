Full Backup

Полная копия всех данных целиком. Самый большой и медленный по созданию бэкап, зато восстановление максимально простое —
всё лежит в одном месте, никаких зависимостей от других копий.

## Свойства

- Самостоятелен: для восстановления нужен только сам этот бэкап.
- Фундамент для incremental и differential — они отсчитывают изменения именно от full.
- Делается периодически (например, раз в неделю), между ними — более лёгкие инкрементальные копии.

## Подводные камни

- Дорог по месту и времени, поэтому редко делается часто.
- Регулярный тест восстановления из full проверяет целостность всей схемы бэкапов.
