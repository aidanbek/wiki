# Incremental Backup

Бэкап только тех данных, что изменились с момента последнего бэкапа любого типа. Самый компактный и быстрый вариант,
поэтому им делают самые частые копии — ценой более сложного восстановления.

## Свойства

- Минимальный размер и время: копируются только дельты с прошлого бэкапа.
- Восстановление = full + все incremental по порядку (цепочка).
- Подходит для частых бэкапов именно благодаря скорости.

## Подводные камни

- Обрыв цепочки (повреждён один из incremental) = потеря всех последующих данных.
- Восстановление медленнее differential: нужно последовательно применить все звенья.
