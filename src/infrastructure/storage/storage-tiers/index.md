# Storage Tiers

Классификация хранилища по соотношению производительность/цена. Часто используемые данные держат на быстром и дорогом
носителе, редкие — на медленном и дешёвом. Распределение по уровням позволяет не платить за SSD-скорость там, где она не
нужна.

## Уровни

- Hot — частый доступ, SSD, дорого и быстро.
- Warm — нечастый доступ, HDD, средняя цена.
- Cold — архив (tape, Glacier), очень дёшево, но медленный и дорогой доступ при извлечении.

## Как работает / подводные камни

- Lifecycle-политики автоматически перемещают данные между уровнями по возрасту/частоте обращений.
- Облачные провайдеры (классы хранения S3) автоматизируют это «из коробки».
- Извлечение из cold-уровня может быть медленным и платным — холодный архив не для данных, нужных «прямо сейчас».
