# HTTP/3 (QUIC)

Третья версия HTTP, работающая не поверх TCP, а поверх **QUIC** — транспортного протокола на базе UDP с встроенными
шифрованием и мультиплексированием. Цель — убрать head-of-line blocking, который остался в [HTTP/2](../http-2/index.md)
из-за TCP.

## QUIC

- Поверх UDP, но даёт надёжную доставку, контроль перегрузки и упорядочивание — как TCP, только в user space.
- TLS 1.3 встроен в сам протокол: рукопожатие соединения и шифрование совмещены (0-RTT / 1-RTT).
- Независимые streams: потеря пакета тормозит только свой stream, остальные едут дальше.
- **Connection ID** не привязан к IP/порту — соединение переживает смену сети (Wi-Fi → LTE) без переподключения.

## Плюсы и подводные камни

- Быстрее устанавливает соединение (меньше round-trip) и устойчивее на мобильных/лоссовых сетях.
- UDP иногда режется корпоративными firewall'ами — нужен fallback на HTTP/2 поверх TCP.
- Логика перенесена в user space → выше нагрузка на CPU; offload в железо пока хуже, чем у TCP.
- Отладка сложнее: трафик зашифрован целиком, привычные TCP-инструменты не помогают.
