Dead-Letter Queue (DLQ)

Отдельная очередь, куда отправляются сообщения, которые не удалось обработать после всех повторов. Снимает «ядовитые»
сообщения с основной очереди, чтобы один битый элемент не блокировал обработку остальных.

## Как работает

- После max retries сообщение перекладывается в DLQ вместо удаления.
- Сообщения с заведомо неисправимой ошибкой (битый формат) можно отправлять в DLQ сразу, без повторов.
- DLQ инспектируют вручную: разбирают причину, чинят данные и при необходимости переотправляют в основную очередь.

## Когда использовать / подводные камни

- Use cases: отладка сбоев, восстановление данных, изоляция проблемных сообщений.
- На рост DLQ нужен алерт — это сигнал систематической проблемы, а не нормальное состояние.
- DLQ без процесса разбора превращается в свалку: важно, чтобы кто-то реально читал и обрабатывал её.
