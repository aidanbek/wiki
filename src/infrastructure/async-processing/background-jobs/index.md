Background Jobs

Долгие задачи, которые выполняются вне цикла запрос-ответ: рассылка писем, обработка видео, генерация отчётов. Запрос не
ждёт их завершения — это защищает API от таймаутов.

## Как работает

- Веб-слой ставит задачу в очередь и сразу отвечает пользователю.
- Воркер-процессы разбирают очередь и выполняют работу в фоне.
- Результат складывается в хранилище (БД, кэш), откуда его можно забрать позже — по job ID или через уведомление.
- Библиотеки берут на себя сериализацию, повторы и мониторинг.

## Когда использовать / подводные камни

- Подходит для всего, что дольше нескольких сотен миллисекунд или зависит от внешних сервисов.
- Пользователю нужно показать статус задачи (in progress / done / failed) — иначе непонятно, что происходит.
- Долгие задачи стоит делать возобновляемыми или дробить на части: воркер может упасть на середине.
