# Shared Hosting

Множество сайтов на одном сервере с общими ресурсами. Самый дешёвый вариант: провайдер сам обслуживает сервер —
обновления, безопасность, настройку. Платой за дешевизну и удобство становится почти полное отсутствие контроля.

## Свойства

- Ресурсы (CPU, память) делятся между всеми сайтами на сервере.
- Управление полностью на провайдере; нет root-доступа, набор ПО ограничен.
- Производительность непредсказуема: «шумный сосед» на том же сервере влияет на тебя.

## Когда подходит

- Простые статические сайты, небольшие блоги на WordPress, лендинги.
- Не подходит для нагруженных приложений, кастомного стека или строгих требований к производительности.
