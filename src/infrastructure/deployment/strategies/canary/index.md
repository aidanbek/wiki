# Canary Deployment

Новая версия сначала получает небольшую долю трафика (5-10%), её метрики наблюдают. Если всё здорово — долю постепенно
увеличивают до 100%. Если есть проблемы — откат затрагивает лишь малую часть пользователей.

## Как работает

- Рядом со стабильной версией поднимается «канареечный» инстанс с малой долей трафика.
- Метрики канарейки (ошибки, latency) сравниваются со стабильной версией.
- При здоровых показателях доля растёт ступенями; при отклонении срабатывает автоматический откат.

## Когда использовать / подводные камни

- Требует инфраструктуры: маршрутизация по долям, сбор метрик, триггеры авто-отката (часто + feature flags).
- Минимизирует радиус поражения от плохой версии — поэтому популярен в высоконагруженных системах.
- Канарейка должна получать репрезентативный трафик, иначе проблема проявится только после полного выката.
