# Service Models (IaaS / PaaS / SaaS)

Уровни облачных услуг различаются тем, сколько стека управляет провайдер, а сколько — ты. Чем выше уровень, тем меньше
эксплуатации и гибкости.

## Уровни

- **IaaS** — арендуешь виртуальные машины, сети, диски; ОС и выше — твоя забота (EC2, Compute Engine). Максимум контроля.
- **PaaS** — провайдер даёт платформу/рантайм, ты деплоишь код (App Engine, Heroku, managed K8s/БД). Меньше эксплуатации.
- **SaaS** — готовое приложение по подписке (Gmail, Salesforce); управляешь только данными и настройками.
- Рядом: **FaaS / serverless** — выполняешь функции без управления серверами (см.
  [serverless](../../fundamentals/app-architecture/serverless/index.md)).

## Shared responsibility

- Чем выше уровень, тем больше ответственности у провайдера: в IaaS патчишь ОС сам, в SaaS — почти ничего.
- Граница ответственности — частый источник инцидентов: «думали, это их зона».

## Как выбирать

- Нужен полный контроль/специфичная ОС/легаси → IaaS.
- Хочешь катить код и не думать об инфраструктуре → PaaS/serverless.
- Задача не профильная (почта, CRM) → SaaS, не строй своё.
