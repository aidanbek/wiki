# Standards

PSR (PHP Standards Recommendations) — рекомендации от PHP-FIG, обеспечивающие совместимость библиотек и единый стиль.
Благодаря им пакеты разных авторов работают вместе, а автозагрузка и интерфейсы стандартизированы.

## Ключевые PSR

- PSR-1 / PSR-12 — базовый стиль кода и его расширенное оформление (PSR-2 устарел).
- PSR-4 — автозагрузка классов по неймспейсам и структуре каталогов (основа Composer autoload).
- PSR-3 — интерфейс логгера (`LoggerInterface`).
- PSR-7 / PSR-15 / PSR-17 — HTTP-сообщения, middleware и фабрики (основа современных HTTP-стеков).
- PSR-11 — контейнер внедрения зависимостей (`ContainerInterface`).
- PSR-6 / PSR-16 — кэширование (пул и простой кэш).

## Зачем

- Интероперабельность: библиотеки, следующие PSR, легко заменяются и комбинируются.
- Единый стиль снижает когнитивную нагрузку и упрощает code review.
- Стандартные интерфейсы (логгер, контейнер, HTTP) позволяют не привязываться к конкретной реализации.

## Инструменты

- PHP_CodeSniffer (`phpcs`/`phpcbf`), PHP-CS-Fixer — проверка и автоисправление под PSR-12.
- Composer применяет PSR-4 для автозагрузки из `composer.json`.

## Подводные камни

- PSR — рекомендации, а не обязательны; в легаси-проектах стиль может расходиться.
- Слепое следование без понимания (например, навязывание PSR-7 везде) добавляет шаблонного кода.
