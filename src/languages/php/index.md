# PHP

Интерпретируемый язык, заточенный под веб-бэкенд. Модель «shared-nothing»: каждый HTTP-запрос исполняется в чистом
окружении, состояние не живёт между запросами — это упрощает горизонтальное масштабирование. Современные версии (8.x)
дают строгую типизацию, JIT, атрибуты и заметный прирост производительности относительно 5.x/7.0.

## Модель исполнения

- Запрос → инициализация → выполнение скрипта → отдача ответа → сброс состояния.
- FPM (FastCGI Process Manager) держит пул воркеров; долгоживущие рантаймы (Swoole, RoadRunner, FrankenPHP) ломают
  shared-nothing ради производительности и persistent-соединений.
- Opcache кэширует скомпилированный байт-код, JIT (8.0+) ускоряет CPU-bound участки.

## Типизация и язык

- Динамическая по умолчанию, но с скалярными type hints, `declare(strict_types=1)`, union/intersection-типами,
  enum, readonly-свойствами, named arguments.
- Композер (Composer) — пакетный менеджер; PSR-стандарты задают автозагрузку и совместимость библиотек.

## Подводные камни

- Историческая непоследовательность стандартной библиотеки (порядок аргументов, именование).
- Без `strict_types` неявные приведения типов скрывают баги.
- Долгоживущие рантаймы требуют осторожности с глобальным состоянием и утечками памяти.
