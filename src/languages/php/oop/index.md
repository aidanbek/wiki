# OOP

Объектная модель PHP: классы, интерфейсы, абстрактные классы и трейты. Современный PHP — полноценно объектный язык с
видимостью, поздней статической привязкой и поддержкой неизменяемости (readonly), что делает его пригодным для DDD и
чистой архитектуры.

## Строительные блоки

- Классы и объекты, видимость `public`/`protected`/`private`, конструктор с property promotion.
- Интерфейсы — контракты без реализации; абстрактные классы — частичная реализация.
- Трейты — горизонтальное переиспользование кода (механизм вместо множественного наследования).
- Enum (8.1) — перечисления, в т.ч. backed enum с методами.

## Особенности модели

- Одиночное наследование классов + множественная реализация интерфейсов.
- Late static binding (`static::`) — обращение к классу, на котором фактически вызван метод.
- `readonly`-свойства и классы для иммутабельных value-объектов.
- Абстракции и интерфейсы — основа инверсии зависимостей (DI-контейнеры).

## Подводные камни

- Трейты с конфликтами имён и скрытой связностью усложняют отладку.
- Глубокие иерархии наследования хрупки — предпочитать композицию.
- Магические методы обходят типобезопасность; интерфейсы и явные методы надёжнее.
