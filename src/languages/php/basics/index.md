# Basics

Базовая семантика PHP: как язык работает с типами, переменными и специальными методами объектов. Понимание этих основ
важнее знания синтаксиса — оно определяет, как код ведёт себя в неочевидных случаях (приведения типов, сравнения,
магия объектов).

## Что важно

- Система типов — скалярные и составные типы, type juggling, строгий vs нестрогий режим, `==` vs `===`.
- Магические методы — `__construct`, `__get`/`__set`, `__call`, `__invoke`, `__toString` и др.
- Переменные передаются по значению, объекты — по «значению-хэндлу» (ссылка на тот же объект).

## Темы

- [Система типов](type-system.md) — типы, приведения, строгий режим, сравнения.
- [Магические методы](magic-methods.md) — специальные методы с двойным подчёркиванием.

## Подводные камни

- Нестрогие сравнения (`==`) и type juggling дают сюрпризы — предпочитать `===` и `strict_types`.
- Злоупотребление магическими методами (`__get`/`__call`) ухудшает читаемость и ломает автодополнение IDE.
