# SPL

Standard PHP Library — встроенный набор структур данных, итераторов и интерфейсов. Покрывает задачи, для которых иначе
пришлось бы тащить зависимости или городить велосипеды на массивах, и часто работает эффективнее по памяти.

## Структуры данных

- `SplStack`, `SplQueue`, `SplDoublyLinkedList` — стек, очередь, двусвязный список.
- `SplPriorityQueue`, `SplHeap` (`SplMinHeap`/`SplMaxHeap`) — приоритетные очереди и кучи.
- `SplFixedArray` — массив фиксированного размера с целочисленными ключами (экономнее обычного массива).
- `SplObjectStorage` — множество/мапа объектов (хранение объектов как ключей).

## Интерфейсы и итераторы

- `Iterator`, `IteratorAggregate` — кастомная итерация в `foreach`.
- `ArrayAccess`, `Countable` — доступ как к массиву и поддержка `count()`.
- `SplObserver`/`SplSubject` — встроенная заготовка паттерна Observer.

## Когда использовать

- Когда нужна конкретная структура с правильной сложностью операций (куча, приоритетная очередь).
- `SplObjectStorage` — когда ключами должны быть объекты.
- `SplFixedArray` — на больших объёмах с целыми индексами ради экономии памяти.

## Подводные камни

- API местами неудобен и менее знаком, чем функции работы с массивами.
- На малых объёмах выигрыш по памяти/скорости незаметен — обычный массив проще.
