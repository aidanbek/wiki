# Go

Компилируемый статически типизированный язык от Google с акцентом на простоту, быструю компиляцию и встроенную
конкурентность. Компилируется в один статический бинарь без внешних зависимостей — отсюда популярность в инфраструктуре
и микросервисах (Docker, Kubernetes, Prometheus написаны на Go).

## Ключевые особенности

- Горутины — легковесные потоки, мультиплексируемые рантаймом на потоки ОС (стартовый стек ~2 КБ).
- Каналы — типизированная передача данных между горутинами; «не общайтесь через память, общайтесь через каналы».
- Сборщик мусора с низкими паузами (concurrent mark-and-sweep), ориентированный на latency.
- Минималистичный синтаксис: нет наследования классов, обобщения добавлены в 1.18, композиция через встраивание.
- Интерфейсы реализуются неявно (duck typing на этапе компиляции).

## Конкурентность

- `go f()` запускает горутину; планировщик (GMP-модель) распределяет их по ядрам.
- Синхронизация: каналы, `sync.Mutex`, `sync.WaitGroup`, `context` для отмены и дедлайнов.
- Race detector (`go test -race`) ловит гонки данных в тестах.

## Инструментарий

- Единый тулчейн: `go build/test/fmt/vet`, модули (`go.mod`) для зависимостей.
- `gofmt` навязывает единый стиль — споров о форматировании нет.
- Богатая стандартная библиотека (net/http, encoding/json) покрывает типовой бэкенд без фреймворков.

## Подводные камни

- Обработка ошибок через возвращаемые значения (`if err != nil`) — многословна.
- `nil`-интерфейсы и горутины-утечки (забытая отмена через context) — частые баги.
- GC и рантайм дают overhead по сравнению с Rust/C++ в задачах с жёсткими требованиями к latency.
