# Java

Статически типизированный объектно-ориентированный язык, исполняемый на JVM. Компилируется в платформенно-независимый
байт-код — «write once, run anywhere». Зрелая экосистема, длинные циклы поддержки (LTS-релизы) и сильный энтерпрайс-стек
делают его дефолтом для крупных систем.

## JVM и рантайм

- Исходник → байт-код (`javac`) → исполнение JVM с JIT-компиляцией в нативный код «горячих» участков.
- Сборка мусора: G1 по умолчанию, ZGC/Shenandoah для низких пауз на больших кучах.
- JVM — общая платформа и для Kotlin, Scala, Clojure, Groovy.

## Язык и типизация

- Сильная статическая типизация, обобщения (generics) со стиранием типов (type erasure).
- ООП с одиночным наследованием классов и множественной реализацией интерфейсов.
- Современные возможности: records, sealed-классы, pattern matching, `var` (вывод типов для локальных переменных).

## Конкурентность

- Потоки ОС, `java.util.concurrent` (пулы, `CompletableFuture`, конкурентные коллекции).
- Virtual threads (Project Loom, Java 21) — легковесные потоки для высокой конкурентности без реактивного стиля.
- Модель памяти JMM описывает видимость изменений между потоками (`volatile`, `synchronized`).

## Экосистема

- Сборка: Maven, Gradle. Фреймворки: Spring (Boot), Jakarta EE, Quarkus, Micronaut.
- Огромный набор библиотек, инструментов профилирования (JFR, async-profiler) и мониторинга.

## Подводные камни

- Многословность (хотя records/lambda сглаживают) и тяжёлый старт классических фреймворков.
- Потребление памяти JVM и время прогрева JIT; для serverless смотрят в сторону GraalVM native image.
