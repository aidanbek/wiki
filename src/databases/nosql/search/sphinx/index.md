# Sphinx

Быстрый и лёгкий движок полнотекстового поиска, изначально заточенный под интеграцию с SQL-БД.

## Особенности

- Индексирует внешние источники (SQL-БД, файлы); простая установка и низкое потребление ресурсов.
- SphinxQL — доступ по MySQL-протоколу (можно «как к таблице»).
- Высокая скорость на типовых сценариях текстового поиска.

## Когда использовать

- Добавить быстрый поиск к существующему MySQL/Postgres-приложению без тяжёлого стека.
- Ограниченные ресурсы, простые требования к поиску.

## Ограничения

- Беднее по функциям, чем Elasticsearch/Solr (агрегации, аналитика, экосистема).
- Менее активная экосистема; для сложного поиска/observability берут ES (см. search).
