# Relational Databases

Хранение данных в таблицах со строгой схемой и связями; работа через SQL и ACID-транзакции. Дефолтный выбор для
большинства операционных приложений (OLTP).

## Темы

- [SQL-Fundamentals](sql-fundamentals/index.md) — базовый язык запросов и команд (DDL/DML/DCL).
- PostgreSQL — расширяемая ORDBMS, частый выбор по умолчанию.
- [MySQL](mysql/index.md) — популярная СУБД, основа LAMP-стека.

## Сильные стороны

- Строгая схема и constraints → целостность данных.
- Мощные запросы (JOIN, агрегаты, оконные функции), зрелые транзакции и инструменты.

## Когда не идеальны

- Очень большой объём/нагрузка с простыми паттернами доступа, изменчивые схемы, граф/поиск — см. [nosql](../nosql/index.md), [scaling](../scaling/index.md).
