# B-Tree Index

Сбалансированное дерево — стандартный индекс в большинстве RDBMS. Универсален: поддерживает и точечный поиск, и
диапазоны, и сортировку.

## Свойства

- O(log n) для search/insert/delete; хранит ключи отсортированными.
- Высокий fanout (сотни потомков на узел) → малая глубина даже на миллионах строк (обычно 3-4 уровня).
- Self-balancing при изменениях; листья часто связаны для эффективного range-scan.

## Что умеет

- Равенство, диапазоны (`>`, `<`, BETWEEN), префиксный LIKE 'abc%', ORDER BY, MIN/MAX.
- Работает для leftmost-prefix составного индекса.

## Когда не идеален

- Точное равенство по «толстым»/высококардинальным ключам — иногда хэш-индекс эффективнее.
- Очень частые записи: поддержка индекса добавляет стоимость (см. [hash-indexes](../hash-indexes/index.md), [compose-indexes](../compose-indexes/index.md)).
