# Hash Indexes

Индекс на основе хэш-функции: ключ → bucket. Даёт амортизированный O(1) поиск по точному равенству.

## Свойства

- Только equality (`=`); не поддерживают range, сортировку, префиксный поиск.
- В среднем быстрее B-tree на чистом равенстве, но выигрыш обычно невелик.

## Когда использовать

- Exact-match нагрузки: key-value lookup, поиск по высококардинальному ключу.

## Почему редко применяют

- B-tree «достаточно быстр» и универсален, поэтому покрывает большинство случаев.
- В Postgres hash-индексы стали crash-safe только с версии 10; раньше их избегали (см. b-tree).
