# HATEOAS

Hypermedia as the Engine of Application State — верхний уровень «зрелости» REST (уровень 3 по модели Ричардсона). Ответы
содержат не только данные, но и **ссылки** на возможные дальнейшие действия; клиент ходит по API через них, а не по
захардкоженным URL.

## Идея

- Ресурс возвращает `links`/`_links` с переходами: например, у заказа в статусе `pending` есть ссылки `cancel` и `pay`,
  а у оплаченного — `refund`.
- Клиент знает входную точку и понимает rel-имена связей; конкретные URL и доступность действий определяет сервер.
- Форматы: HAL, JSON:API, Siren, Collection+JSON.

## Плюсы

- **Discoverability** и слабая связанность: сервер меняет URL и доступные действия, не ломая клиентов.
- Доступные переходы зависят от состояния — бизнес-правила выражены в самом ответе.

## Подводные камни

- На практике редко внедряют полностью: клиенты всё равно зашивают логику, выгода не оправдывает сложность.
- Раздувает ответы и требует более «умного» клиента.
- Чаще ограничиваются прагматичным минимумом — ссылки на пагинацию и связанные ресурсы, без полного гипермедиа-движка.
