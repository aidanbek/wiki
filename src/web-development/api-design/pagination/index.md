# Pagination

Отдача больших наборов данных порциями вместо всего сразу. Главный выбор — между удобством (прыжок на любую страницу) и
производительностью/консистентностью на больших объёмах.

## Подходы

- [Offset-based](offset-based/index.md) — `?offset=20&limit=10`; просто, но медленно на больших смещениях.
- [Page-based](page-based/index.md) — `?page=3&per_page=10`; те же минусы, но дружелюбные URL.
- [Cursor-based](cursor-based/index.md) — курсор на позицию; быстро и консистентно, но без прыжка на страницу N.

## Как выбрать

- Небольшие данные, админки → offset/page (нужен прыжок на страницу).
- Большие данные, ленты, infinite scroll → cursor (производительность и консистентность).
