API Documentation

Машиночитаемое описание API: эндпоинты, параметры, схемы запросов/ответов, авторизация. Из такого описания
генерируют интерактивные доки, клиентские SDK и моки — поэтому документация перестаёт расходиться с реальностью.

## Разделы

- [OpenAPI](open-api/index.md) — сама спецификация (формат описания REST API).
- [Swagger](swagger/index.md) — набор инструментов вокруг OpenAPI.

## Зачем

- API-first design: описать контракт до реализации.
- Сокращает время onboarding разработчиков, которые подключаются к API.
