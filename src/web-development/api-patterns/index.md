API Patterns

Паттерны построения API поверх множества микросервисов: как собрать данные из нескольких сервисов и как подать их
клиенту удобно, не превращая систему в клубок вызовов.

## Разделы

- [API Composition](api-composition/index.md) — сбор данных из нескольких сервисов в один ответ.
- [BFF](bff/index.md) — отдельный backend под каждый тип клиента.
- [GraphQL Federation](graphql-federation/index.md) — единая GraphQL-схема из подграфов разных сервисов.
- [API Mesh](api-mesh/index.md) — децентрализованное управление API без центрального шлюза.

## Сквозная мысль

- Общий trade-off: гибкость композиции vs сложность (производительность, partial failures, согласованность данных).
