Data Serialization

Форматы представления данных для передачи и хранения. Основной выбор — между текстовыми (читаемые, но объёмные) и
бинарными (компактные и быстрые, но требуют схемы и инструментов).

## Форматы

- [JSON](json/index.md) — текстовый, человекочитаемый, стандарт для REST API.
- [Protobuf](protobuf/index.md) — бинарный, по схеме, для gRPC и межсервисного обмена.
- [Avro](avro/index.md) — бинарный, гибкая schema evolution, популярен в big data.
- [MessagePack](msgpack/index.md) — бинарный «JSON без схемы», компромисс по простоте/эффективности.

## Как выбирать

- Публичные API, простота, отладка → JSON.
- Высокая нагрузка, межсервисный обмен, строгая схема → Protobuf/Avro.
- Кеши, IPC, где JSON слишком объёмен → MessagePack.
