# Realtime

Способы доставлять обновления клиенту в реальном времени, без постоянного опроса сервера. Выбор зависит от того, нужна
ли двусторонняя связь и какие ограничения окружения.

## Технологии

- [WebSockets](websockets/index.md) — полнодуплексный канал, обе стороны шлют данные.
- [Server-Sent Events](server-sent-events/index.md) — однонаправленный поток server→client поверх HTTP.
- [Long Polling](long-polling/index.md) — эмуляция realtime через удерживаемые HTTP-запросы; fallback.

## Как выбрать

- Нужен двусторонний обмен (чат, игры) → WebSockets.
- Только сервер шлёт обновления (ленты, уведомления) → SSE (проще, дружелюбен к firewall).
- WebSockets/SSE недоступны → long polling как запасной вариант.
