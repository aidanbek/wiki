# Pulumi

IaC, где инфраструктура описывается на настоящих языках программирования (TypeScript, Python, Go, C#), а не на DSL.
Модель та же, что у [Terraform](../terraform/index.md) — desired state, провайдеры, state — но с мощью обычного кода.

## Чем отличается от Terraform

- Циклы, условия, функции, классы, тесты — без ограничений декларативного DSL.
- Переиспользование через обычные пакеты/модули языка и его экосистему.
- Совместимо с Terraform-провайдерами; state можно хранить в Pulumi Cloud или своём бэкенде.

## Когда выбирать

- Команда сильна в разработке и хочет настоящую логику, типы и юнит-тесты для инфраструктуры.
- Сложная динамическая генерация ресурсов, где HCL становится громоздким.

## Подводные камни

- Полнота языка — это и риск: легко спрятать сложность и побочные эффекты, которых в декларативном HCL не бывает.
- Тот же критичный **state** и те же требования к блокировке и хранению секретов, что у Terraform.
- Меньше готовых примеров/модулей сообщества, чем у Terraform.
