# Infrastructure as Code (IaC)

Управление инфраструктурой через версионируемый код вместо ручных кликов в консоли. Серверы, сети, базы и права
описываются в файлах, проходят review и применяются автоматически — инфраструктура становится воспроизводимой и
аудируемой.

## Разделы

- [Terraform](terraform/index.md) — декларативный provisioning ресурсов у любых провайдеров.
- [Pulumi](pulumi/index.md) — IaC на обычных языках программирования.
- [Ansible](ansible/index.md) — конфигурация и оркестрация по SSH без агента.
- [Helm](helm/index.md) — пакетный менеджер и шаблонизация манифестов Kubernetes.
- [GitOps](gitops/index.md) — Git как единственный источник правды о состоянии.

## Ключевые идеи

- **Декларативно vs императивно** — описываем желаемое состояние, инструмент сам считает разницу (terraform plan).
- **Идемпотентность** — повторный прогон не ломает уже корректные ресурсы.
- **Immutable infrastructure** — не править сервер вручную, а пересоздавать из кода (борьба с configuration drift).

## Зачем это знать

- Воспроизводимость окружений (dev = staging = prod) и быстрое восстановление после сбоя.
- Code review и история изменений для инфраструктуры, как для обычного кода.
- Основа для автоматизации, масштабирования и [CI/CD](../tools-and-setup/ci-cd/index.md).
