# Helm

Пакетный менеджер для [Kubernetes](../../infrastructure/containerization/k8s/index.md). Группирует множество манифестов в
версионируемый пакет — **chart** — с шаблонами и параметрами, чтобы один и тот же релиз ставить в разные окружения.

## Понятия

- **Chart** — пакет с шаблонами манифестов и метаданными.
- **Values** — параметры (`values.yaml`), подставляемые в шаблоны; переопределяются на установку.
- **Release** — установленный экземпляр чарта в кластере; Helm хранит историю ревизий.
- `helm install/upgrade/rollback` — управление релизом с откатом на прошлую ревизию.

## Зачем

- Не копировать YAML под каждое окружение — один чарт + разные values (dev/staging/prod).
- Готовые чарты для типового софта (БД, ingress, мониторинг) из репозиториев.
- Удобный rollback и версионирование выката.

## Подводные камни

- Шаблонизация текстом (Go templates) — легко получить невалидный YAML; помогают `helm lint`, `--dry-run`, `helm diff`.
- Сложные чарты превращаются в нечитаемую «лапшу» из условий — иногда проще Kustomize или чистые манифесты.
- Часто ставят в связке с [GitOps](../gitops/index.md): чарт + values в Git, выкат через Argo CD/Flux.
