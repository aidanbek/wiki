# Repository

Абстракция, инкапсулирующая доступ к данным и представляющая коллекцию доменных объектов «в памяти».

## Структура

- Интерфейс в domain-слое, реализация в infrastructure: `userRepository.findById(id)` скрывает SQL/NoSQL.
- Работает с Aggregate Roots (в DDD), а не с произвольными таблицами/сущностями.

## Зачем

- Тестируемость (mock-репозиторий), изоляция persistence от бизнес-логики, единая точка для запросов.

## Trade-offs

- Чистая граница домена и хранилища.
- Риск «дырявой» абстракции (протекание деталей ORM), дублирование с возможностями ORM; не превращать в свалку методов (
  см. fundamentals/app-architecture/ddd, hexagonal).
