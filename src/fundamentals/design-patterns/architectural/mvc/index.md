MVC (Model-View-Controller)

Разделение приложения на три слоя с разными обязанностями — классика для UI-приложений.

## Компоненты

- Model — бизнес-логика и данные.
- View — представление (отрисовка).
- Controller — обработка ввода и координация: принимает запрос, обновляет Model, выбирает View.

## Поток

- Controller → меняет Model → Model уведомляет View (часто через Observer) → View перерисовывается.

## Варианты и trade-offs

- Изолирует бизнес-логику от представления, улучшает тестируемость.
- Вариации MVP и MVVM меняют направление зависимостей и роль посредника (binding в MVVM); граница Controller/Model часто размывается (см. observer).
