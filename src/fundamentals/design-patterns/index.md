Design Patterns

Повторно используемые решения типовых проблем проектирования — общий словарь для обсуждения архитектуры кода.

## Группы в этом разделе

- GoF — 23 классических паттерна (creational, structural, behavioral).
- Architectural — паттерны уровня системы (MVC, CQRS, Event Sourcing, Repository).
- Dependency-Management — управление зависимостями (DI, IoC, service container/locator).

## Как применять

- Паттерн — инструмент с trade-offs, а не самоцель; неуместный паттерн добавляет сложность (см. design-principles, kiss,
  yagni).
- Сначала простое решение, паттерн — когда проблема реально проявилась.
