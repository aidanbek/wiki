# Flyweight

Разделение общего состояния между множеством мелких объектов для экономии памяти.

## Структура

- Intrinsic state (общий, разделяемый) vs extrinsic state (уникальный, передаётся снаружи).
- Пример: у объекта `Character` шрифт/глиф — intrinsic (один на всех), позиция — extrinsic.
- Factory управляет пулом и переиспользует объекты с одинаковым intrinsic state.

## Когда использовать

- Очень много похожих объектов: рендеринг текста, частицы, тайлы карты, игровые объекты.

## Trade-offs

- Существенная экономия памяти.
- Усложнение кода (разделение состояния), extrinsic state нужно хранить/передавать отдельно.
