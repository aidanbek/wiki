Facade

Упрощённый интерфейс к сложной подсистеме — единая точка входа, скрывающая взаимодействие множества классов.

## Структура

- `OrderFacade.placeOrder()` внутри координирует Inventory, Payment, Shipping, Notification.
- Клиент видит один высокоуровневый метод вместо десятка вызовов.

## Когда использовать

- Снизить coupling между клиентом и сложной подсистемой.
- Дать удобный API для частых сценариев, оставив доступ к деталям для редких.

## Trade-offs

- Упрощает использование, не запрещая прямой доступ к подсистеме.
- Может разрастись в God Object, если на него вешать всё (см. mediator, adapter).
