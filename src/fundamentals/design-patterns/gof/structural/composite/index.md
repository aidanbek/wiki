# Composite

Композиция объектов в древовидные структуры part-whole с единообразной работой с одиночными объектами и их группами.

## Структура

- `Component` — общий интерфейс; `Leaf` — лист, `Composite` — узел, содержащий другие Component.
- Пример: FileSystem — `File` и `Directory` с одинаковым интерфейсом.

## Когда использовать

- Иерархии «часть-целое»: меню, дерево UI, файловая система, организационная структура.
- Клиент должен обрабатывать лист и контейнер единообразно.

## Trade-offs

- Рекурсивная композиция, операции распространяются по дереву автоматически.
- Сложно ограничить, какие типы допустимы в контейнере (общий интерфейс «размывает» различия).
