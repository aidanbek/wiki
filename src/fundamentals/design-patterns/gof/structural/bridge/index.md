# Bridge

Разделяет абстракцию и реализацию, позволяя им изменяться независимо — композиция вместо наследования для двух осей
вариативности.

## Структура

- `Shape` (Circle, Square) и `Renderer` (Vector, Raster); Abstraction делегирует Implementor.
- Вместо `Circle+Vector`, `Circle+Raster`, `Square+Vector`… — две независимые иерархии.

## Когда использовать

- Есть два (и более) независимых измерения изменений → иначе комбинаторный взрыв подклассов.
- Реализацию нужно подменять в runtime.

## Trade-offs

- Гибкость и расширяемость по обеим осям.
- Дополнительная сложность; оправдан при реальной двумерной вариативности (см. [strategy](../../behavioral/strategy/index.md)).
