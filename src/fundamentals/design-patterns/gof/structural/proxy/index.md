Proxy

Суррогат, контролирующий доступ к другому объекту — placeholder с тем же интерфейсом, добавляющий контроль.

## Виды

- Virtual Proxy — ленивая инициализация дорогого объекта (`ImageProxy` грузит картинку при первом обращении).
- Protection Proxy — контроль прав доступа; Remote Proxy — представитель удалённого объекта; Smart Proxy — доп. логика (счётчики, кэш).

## Когда использовать

- Нужно вклинить поведение (lazy load, кэш, права, логирование) без изменения реального объекта.

## Trade-offs

- Прозрачен для клиента (общий интерфейс).
- Похож на Decorator (добавляет поведение) и Adapter (меняет интерфейс) — отличается намерением: контроль доступа.
