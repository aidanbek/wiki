# Adapter

Конвертирует интерфейс класса в интерфейс, ожидаемый клиентом — обёртка для несовместимых интерфейсов.

## Структура

- Legacy `oldCalculate()` оборачивается адаптером с ожидаемым `ICalculator.compute()`.
- Варианты: object adapter (композиция, чаще) и class adapter (множественное наследование).

## Когда использовать

- Интеграция со сторонними библиотеками и legacy-кодом без их изменения.
- Приведение разнородных API к единому интерфейсу.

## Trade-offs

- Минимальные изменения существующего кода.
- Лишний уровень косвенности; не путать с Facade (упрощает) и Decorator (добавляет поведение).
