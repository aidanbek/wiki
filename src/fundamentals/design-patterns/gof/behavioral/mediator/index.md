# Mediator

Объект, инкапсулирующий взаимодействие множества объектов — централизует связи вместо прямых ссылок друг на друга.

## Структура

- Colleagues общаются через Mediator и не знают друг о друге; `ChatRoom` координирует `User`-ов.
- Связи n-to-n превращаются в n-to-1.

## Когда использовать

- Много объектов с запутанными взаимными связями (UI-формы, чат, диспетчеризация).
- Логику координации хочется собрать в одном месте.

## Trade-offs

- Снижает связанность между участниками.
- Mediator может разрастись в God Object — вся сложность переезжает в него (см. [facade](../../structural/facade/index.md), [observer](../observer/index.md)).
