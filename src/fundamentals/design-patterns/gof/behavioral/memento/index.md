Memento

Сохранение и восстановление состояния объекта без нарушения инкапсуляции — снимок для undo/redo.

## Структура

- `Originator` создаёт Memento (снимок) и восстанавливается из него; `Caretaker` хранит снимки, но не видит их содержимое.
- Memento непрозрачен для всех, кроме Originator.

## Когда использовать

- Undo-стеки, чекпоинты, откат транзакций, сохранение состояния редактора/игры.

## Trade-offs

- Сохраняет инкапсуляцию (Caretaker не лезет внутрь).
- Снимки могут быть дорогими по памяти; для частых сохранений нужны инкрементальные стратегии (см. command).
