# Visitor

Добавление операций к структуре объектов без изменения их классов — операция выносится в отдельный visitor.

## Структура

- `Element.accept(Visitor)` + `Visitor.visit(ConcreteElement)` — двойная диспетчеризация (double dispatch).
- Новая операция = новый Visitor, без правки классов Element.

## Когда использовать

- Стабильная иерархия элементов + часто добавляются новые операции: обход AST в компиляторах, сериализация, отчёты.

## Trade-offs

- Легко добавлять операции, логика операции собрана в одном месте.
- Тяжело добавлять новые типы Element (надо менять всех visitor-ов); нужен доступ к internals — частично ломает
  инкапсуляцию.
