# Command

Инкапсуляция запроса как объекта — позволяет параметризовать клиентов операциями, ставить их в очередь, логировать и
отменять.

## Структура

- Интерфейс `Command` с `execute()`; `ConcreteCommand` хранит receiver и параметры; `Invoker` вызывает, не зная деталей.

## Когда использовать

- Undo/redo (хранение состояния), макрокоманды (композиция), очереди задач, UI actions.
- Нужно отвязать инициатора действия от его исполнителя.

## Trade-offs

- Decoupling sender/receiver, легко добавлять новые команды; основа CQRS и async-операций.
- Много мелких классов-команд (см. fundamentals/design-patterns/architectural/cqrs).
