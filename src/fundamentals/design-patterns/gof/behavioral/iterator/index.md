# Iterator

Последовательный доступ к элементам коллекции без раскрытия её внутреннего представления.

## Структура

- Методы `hasNext()`/`next()`; итератор внешний (управляет клиент) или внутренний (управляет коллекция).
- Коллекция отдаёт итератор через `getIterator()`/`iterator()`.

## Когда использовать

- Единый способ обхода разных структур данных; несколько одновременных проходов по одной коллекции.
- Разные стратегии обхода (DFS/BFS) за одним интерфейсом.

## Trade-offs

- Скрывает детали хранения, унифицирует перебор.
- В большинстве языков встроен (for-each, generators) — отдельная реализация нужна редко.
