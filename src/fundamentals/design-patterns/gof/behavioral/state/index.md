# State

Изменение поведения объекта при смене внутреннего состояния — объект «как будто меняет класс».

## Структура

- Каждое состояние — отдельный класс, реализующий общий интерфейс; `Context` делегирует текущему State.
- Переходы явные: State меняет `Context.state` или Context управляет переходами.

## Когда использовать

- Конечные автоматы: заказ (new → paid → shipped), соединение, проигрыватель.
- Много `if/switch` по полю-состоянию с разным поведением.

## Trade-offs

- Устраняет разветвлённый conditional logic, состояния явные, легко добавлять новые.
- Больше классов; похож на Strategy, но State ещё управляет переходами между собой (см. strategy).
