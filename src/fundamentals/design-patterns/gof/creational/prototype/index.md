Prototype

Создание объектов клонированием прототипа вместо конструирования с нуля — копирование готового экземпляра.

## Структура

- Метод `clone()` возвращает копию; различают shallow copy (ссылки) и deep copy (полное дублирование).
- Прототипное наследование в JavaScript построено на этой идее.

## Когда использовать

- Создание дорого (запрос в БД, сложная инициализация) — дешевле скопировать.
- Нужна динамическая конфигурация: клонировать базовый объект и поменять часть полей.

## Trade-offs

- Избегает жёсткой привязки к конкретным классам.
- Сложность с глубоким копированием графов объектов и циклическими ссылками.
