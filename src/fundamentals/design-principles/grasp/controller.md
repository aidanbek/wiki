# Controller

Первый объект за UI-слоем, координирующий системные операции — фасад или use case.

## Суть

- Controller всей системы (`SystemController`) или сценария (`ProcessSaleController`).
- Не содержит бизнес-логики — только делегирует запросы экспертам.

## Зачем

- Разделяет UI и доменную модель; единая точка входа для каждого действия пользователя (см.
  design-patterns/architectural/mvc).
