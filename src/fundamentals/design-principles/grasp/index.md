# GRASP (General Responsibility Assignment Software Patterns)

Девять фундаментальных паттернов распределения ответственности — про то, какой объект должен делать что, а не про
структуры кода.

## Паттерны

- Information Expert — ответственность туда, где данные.
- Creator — кто создаёт объект.
- Controller — кто обрабатывает системные события.
- Low Coupling / High Cohesion — слабая связанность, высокая связность.
- Polymorphism, Pure Fabrication, Indirection, Protected Variations.

## Зачем

- Ментальная модель для проектных решений об ответственности; предшественник и дополнение GoF-паттернов.
- Основа осознанного ООП-дизайна (см. design-principles/solid, low-coupling/high-cohesion в подразделах).
