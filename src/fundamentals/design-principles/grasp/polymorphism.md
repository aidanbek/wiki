Polymorphism

Когда поведение зависит от типа, используй полиморфные операции вместо условных конструкций.

## Суть

- Вместо `if (type == "card") … else if (type == "cash")` — интерфейс `Payment` с `CardPayment`, `CashPayment`.

## Зачем

- Устраняет type-checking, делает систему открытой для расширения (см. solid/open-closed).
- Новые типы добавляются без изменения существующего кода.
