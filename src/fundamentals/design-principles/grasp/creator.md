# Creator

Кто должен создавать экземпляры класса A.

## Правило

- B создаёт A, если B: агрегирует/содержит A, записывает A, тесно использует A или имеет данные инициализации A.
- Примеры: `Order` создаёт `OrderLine`, `ShoppingCart` создаёт `Order`.

## Зачем

- Централизует создание, предотвращает разбросанные `new` по системе.
- Для сложного конструирования не подходит — там нужен Factory (см. design-patterns/gof/creational).
