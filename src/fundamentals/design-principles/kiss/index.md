# KISS (Keep It Simple, Stupid)

Простота — ключевая цель дизайна; избегай ненужной сложности. Решение должно быть настолько простым, насколько
возможно, но не проще.

## Суть

- Сложность — враг надёжности, понимания и сопровождения.
- Применимо на всех уровнях: имена переменных, функции, модули, архитектура.

## Как применять

- Выбирать самое простое решение, решающее задачу; не добавлять «на будущее» (см. [yagni](../yagni/index.md)).
- Прятать неизбежную сложность за понятными абстракциями.

## Нюансы

- Простота ≠ примитивность: цель — элегантность через минимализм.
- Иногда «простое сейчас» конфликтует с расширяемостью — решать по реальным требованиям.
