# YAGNI (You Aren't Gonna Need It)

Не реализуй функциональность, пока она реально не понадобится — только то, что требуется сейчас.

## Суть

- Преждевременная абстракция дороже дублирования; спекулятивный код создаёт мёртвые ветки и ложную сложность.
- Из Extreme Programming, противовес overengineering.

## Как применять

- Решать сегодняшнюю задачу; расширять по мере появления реальных требований.
- Работает в паре с рефакторингом: добавляй гибкость, когда она понадобилась, а не заранее.

## Баланс

- Не оправдание для грязного кода — простота ≠ небрежность.
- Иногда дешёвая точка расширения сейчас экономит дорогую переделку потом — судить по вероятности (см. [kiss](../kiss/index.md), [dry](../dry/index.md)).
