# Reverse Proxy

Сервер между клиентами и origin, кэширующий ответы — Varnish, Nginx, Squid.

## Возможности

- Терминирует клиентские соединения, агрегирует запросы к backend, кэширует результаты.
- Кэш персонализированного контента (Vary), сложные правила инвалидации, compression, SSL offloading.
- Гибкая конфигурация (VCL в Varnish), purge API для инвалидации.

## Зачем

- Первая линия защиты origin; способен принимать в 10–100× больше нагрузки (см. [system-level/cdn](../cdn/index.md)).
