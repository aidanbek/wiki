CDN (Content Delivery Network)

Географически распределённая сеть edge-серверов, кэширующих контент близко к пользователям — изображения, CSS, JS,
видео.

## Как работает

- Points of Presence (PoP) в разных регионах; запрос идёт к ближайшему.
- **Push** (контент загружается заранее) vs **Pull** (cache on first request).

## Зачем

- Снижает latency (близость), разгружает origin, смягчает DDoS (распределённость).
- Cloudflare, Akamai, AWS CloudFront; критично для глобальных приложений и медиа.
