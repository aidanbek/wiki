Browser Cache

Встроенный кэш браузера, хранящий ресурсы локально на устройстве — самый быстрый уровень.

## Виды и управление

- Memory cache (в RAM, живёт пока открыта вкладка) и disk cache (persistent между сессиями).
- Управляется HTTP cache headers от сервера (Cache-Control).
- Service Workers дают программируемый контроль (PWA); hard refresh (Ctrl+F5) обходит кэш.
