# Read-Through

Кэш сам загружает данные из DB при miss — приложение работает только с кэшем.

## Как работает

- `cache.get(key)` → при miss кэш сам fetch'ит из источника, сохраняет и возвращает.
- Логика загрузки централизована в кэш-слое (настраивается data loader).

## Trade-offs

- Упрощает код приложения — нет fallback-логики.
- Холодный кэш медленнее: первый miss вызывает synchronous load (ср. cache-aside, где грузит приложение).
