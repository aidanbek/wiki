# Write-Around

Запись в DB минуя кэш — чтобы не засорять кэш данными, которые редко читают.

## Как работает

- При записи: write в DB напрямую, инвалидация записи в кэше (если была).
- При чтении: cache-aside или read-through.

## Когда использовать

- Workloads, где записи редко читаются сразу: logs, analytics, bulk imports.
- Меньше cache churn, место сохраняется под hot data; минус — чтение сразу после записи будет miss (ср. write-through).
