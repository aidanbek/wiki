# FILO (First In Last Out)

Удаляет самую новую запись — stack-семантика, противоположность FIFO.

## Применимость

- В кэшировании почти не встречается; ближе к структурам данных (call stack, undo history).
- Может пригодиться для временных данных, где новое быстро устаревает; контринтуитивна для типичных кэш-паттернов.
