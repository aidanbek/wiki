# FIFO (First In First Out)

Удаляет самую старую по времени добавления запись — queue-семантика, простейший алгоритм.

## Свойства

- Не учитывает паттерны доступа, только порядок добавления.
- Легко реализовать (circular buffer), минимальный overhead, предсказуемое поведение.

## Trade-offs

- Плохой hit rate: популярная, но старая запись вытеснится раньше недавней редкой.
- Годится при равномерном доступе или как temporary buffer; baseline для сравнения (ср. lru, lfu).
