# Ban

Удаление множества записей по паттерну/условию — групповая инвалидация.

## Как работает

- Например, в Varnish: `ban req.url ~ "^/articles/"` удаляет все статьи.
- Работает по метаданным (URL, headers, tags), а не по точному ключу.

## Trade-offs

- Мощнее purge (целые разделы, все статьи автора), но медленнее — может требовать сканирования кэша.
- Нужна поддержка кэш-системы (Varnish, Fastly) — есть не у всех (ср. purge).
