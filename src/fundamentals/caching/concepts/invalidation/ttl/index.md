# TTL (Time To Live)

Время жизни записи, после которого она считается stale — простейшая стратегия инвалидации.

## Как работает

- Задаётся при записи: `set(key, value, ttl=300)`. Аналоги: `Cache-Control: max-age` (HTTP), `EXPIRE` (Redis).
- Пассивно: данные удаляются не ровно по истечении, а при следующем обращении или фоновом процессе.

## Выбор TTL

- По частоте изменения данных: статика — дни/месяцы, API-ответы — минуты/часы, session — часы.
