# Linear Search (Последовательный поиск)

Перебор элементов по порядку до нахождения цели или конца коллекции — простейший универсальный алгоритм.

## Сложность

- O(n) average/worst, O(1) best (элемент в начале).

## Особенности

- Не требует сортировки и индексов — единственный вариант для unsorted данных без доп. структур.
- Эффективен на малых коллекциях (n < 10–20), где overhead сложных алгоритмов не окупается.
- Оптимизации: sentinel (убрать проверку границ), move-to-front (locality), early exit (см. binary).
