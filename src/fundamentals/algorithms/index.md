# Algorithms

Алгоритмы (последовательности шагов для решения задачи) и структуры данных (способы организации данных для эффективного
доступа) — раздел computer science о методах обработки данных.

## Зачем разбираться

- **Эффективность** — правильный выбор алгоритма/структуры сокращает время выполнения и потребление памяти.
- **Понимание основ** — развивает абстрактное мышление и умение решать задачи; лежит в основе всех систем.

## Разделы

- **Sorting** и **Searching** — базовые алгоритмы.
- **Data structures** — массивы, списки, деревья, графы, хеш-таблицы, множества.
