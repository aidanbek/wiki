# Persistent Data Structures

Иммутабельные структуры, сохраняющие все предыдущие версии после изменения через structural sharing.

## Идея

- Вместо мутации копируются только затронутые узлы, остальное переиспользуется.
- Применение: функциональное программирование, системы версионирования, temporal databases.
