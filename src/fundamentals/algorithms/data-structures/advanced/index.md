# Advanced Data Structures

Структуры за пределами базовых — под специфичные задачи: range queries, версионирование, строки, кэширование.

## Структуры

- **Fenwick / Segment tree** — запросы и обновления на диапазонах.
- **Skip list** — вероятностная замена сбалансированным деревьям.
- **Suffix tree** — задачи на строках.
- **Persistent structures** — иммутабельность с историей версий.
- **LRU cache** — вытеснение по давности использования.
