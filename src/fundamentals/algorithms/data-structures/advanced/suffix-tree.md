Suffix Tree (Суффиксное дерево)

Сжатое префиксное дерево всех суффиксов строки; строится за O(n) алгоритмом Укконена.

## Применение

- Поиск подстрок, longest common substring, pattern matching за линейное время.
- Фундамент биоинформатики, анализа ДНК, полнотекстового поиска (см. ../trees/trie/index.md).
