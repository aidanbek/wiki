Fenwick Tree (Дерево Фенвика)

Компактная структура для префиксных сумм и точечных обновлений за O(log n); навигация через битовые операции.

## Когда использовать

- Частые запросы суммы на префиксе/отрезке вместе с точечными обновлениями.
- Проще и легче по памяти, чем segment tree, но менее универсальна (см. segment-tree).
