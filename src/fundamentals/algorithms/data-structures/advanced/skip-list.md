Skip List

Вероятностная альтернатива сбалансированным деревьям с многоуровневой системой указателей.

## Как работает

- Элементы случайно получают «высоту», образуя иерархию для поиска O(log n) в среднем.
- Проще красно-чёрных деревьев, естественно поддерживает параллелизм (см. ../trees/red-black.md).
