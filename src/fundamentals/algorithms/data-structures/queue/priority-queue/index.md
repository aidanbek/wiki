# Priority Queue (Очередь с приоритетами)

Очередь, где у каждого элемента есть приоритет; элементы обслуживаются по приоритету, при равенстве — по порядку
поступления.

## Реализации

- Массив, связный список, куча (heap — обычно лучший выбор: вставка/извлечение за O(log n)) или binary search tree.
