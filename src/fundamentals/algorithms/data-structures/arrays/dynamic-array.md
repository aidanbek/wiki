Dynamic Array (Динамический массив)

Массив с изменяемым размером: хранит ёмкость (capacity) и число заполненных элементов.

## Как растёт

- Пока есть место — заполняется; при переполнении выделяется новый массив большей ёмкости, данные копируются.
- Амортизированная вставка в конец — O(1); вставка в середину дорога (сдвиг хвоста).
