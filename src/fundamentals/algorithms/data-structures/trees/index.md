Tree (Дерево)

Иерархическая структура: данные лежат в узлах. У каждого узла один родитель и любое число дочерних — узлы расходятся,
как
ветви.

## Термины

- Корень (root) — узел без родителя; лист (leaf) — узел без детей; высота — длина пути от корня до самого глубокого
  листа.

## Виды

- Binary tree, binary search tree, B-tree, heap, trie; самобалансирующиеся — AVL, red-black.
