Red-Black Tree (Красно-чёрное дерево)

Самобалансирующееся BST, где каждый узел красный или чёрный; набор правил гарантирует приблизительную балансировку.

## Правила

- Корень и листья (NIL) чёрные; у красного узла дети чёрные; на всех путях от узла до листьев одинаковое число чёрных узлов.
- Балансировка — повороты + перекраска при вставке/удалении.

## Свойства

- Высота O(log n); балансирован слабее AVL, но дешевле вставка/удаление.
- Используется в `std::map`, Java TreeMap, ядрах ОС (см. avl.md).
