# Bloom Filter (Фильтр Блума)

Вероятностная структура для проверки членства в множестве — компактная, с допустимыми false positives.

## Как работает

- Bit array размером m + k хэш-функций; добавление ставит k битов в позициях `hash_i(element)`.
- Проверка: все k битов установлены → «возможно в множестве»; хоть один нет → «точно нет».
- False positive возможен, false negative — невозможен.

## Свойства и применение

- ~10 бит на элемент для 1% false positive; оптимально k ≈ (m/n)·ln2.
- Нельзя удалять (кроме counting bloom filter) и перечислять содержимое.
- Применение: проверка перед дорогим запросом (DB/disk), CDN edge, spell checkers.
