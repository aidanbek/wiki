# Union-Find (Система непересекающихся множеств)

Структура для disjoint sets с двумя операциями: Find (к какому множеству принадлежит элемент) и Union (объединить два
множества).

## Как работает

- Лес деревьев: каждое дерево — множество, корень — его representative.
- Find возвращает корень; Union делает корень одного ребёнком другого.

## Оптимизации

- **Union by rank/size** — меньшее дерево к большему → высота O(log n).
- **Path compression** — при Find все узлы пути становятся прямыми детьми корня.
- С обеими: амортизированная O(α(n)), inverse Ackermann — практически константа.
- Применение: Kruskal's MST, динамическая связность графов, connected components (см. disjoint.md).
