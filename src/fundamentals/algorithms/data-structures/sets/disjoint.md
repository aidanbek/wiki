# Disjoint Sets (Непересекающиеся множества)

Разбиение универсального множества на взаимоисключающие группы: каждый элемент принадлежит ровно одному подмножеству.

## Зачем

- Представление equivalence relations — элементы в одном множестве эквивалентны.
- Применение: компоненты связности графа, кластеризация, проверка цикла в Kruskal's MST.

## Реализация

- Эффективно через Union-Find: быстрое объединение и проверка принадлежности (см. union-find.md).
- Динамична: можно добавлять и объединять множества, но обычно нельзя разделять.
