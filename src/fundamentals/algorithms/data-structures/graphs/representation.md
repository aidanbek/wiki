# Representation (Представление графов)

Способ хранения графа — компромисс между памятью и скоростью операций.

## Способы

- **Adjacency Matrix** — 2D-массив [V×V]: O(1) проверка ребра, O(V²) память — плохо для разреженных графов.
- **Adjacency List** — массив списков соседей: O(V+E) память, O(degree) проверка ребра — оптимум для разреженных (
  большинство реальных).
- **Edge List** — список рёбер `(u, v, weight)`: компактно, но O(E) на операцию; для некоторых алгоритмов (Kruskal).

## Выбор

- Зависит от плотности (E относительно V²) и операций: matrix для плотных и быстрых проверок рёбер, list для разреженных
  и обходов.
