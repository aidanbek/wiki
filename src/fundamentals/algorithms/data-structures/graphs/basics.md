# Basics (Основы графов)

Граф G=(V,E) — набор вершин (vertices) и рёбер (edges), соединяющих пары вершин; моделирует отношения между объектами.

## Понятия

- Directed (digraph) — рёбра направленные; undirected — связи симметричны.
- Степень вершины (число смежных рёбер), путь (последовательность вершин через рёбра), цикл (путь в начало), связность (
  есть путь между любыми вершинами).

## Где встречается

- Соцсети (люди/дружба), маршруты (города/дороги), интернет, зависимости задач, молекулы — базовая абстракция для
  networks.
