# Minimum Spanning Tree (Минимальное остовное дерево)

Подмножество рёбер связного взвешенного графа, соединяющее все вершины с минимальной суммой весов — дерево (V−1 рёбер,
без циклов, связное).

## Алгоритмы

- **Kruskal** — сортируем рёбра по весу, добавляем, если не создаёт цикл (Union-Find для проверки): O(E log E), хорош
  для разреженных.
- **Prim** — растущее дерево из стартовой вершины, добавляем минимальное ребро к новой вершине: O((V+E)log V), хорош для
  плотных.

## Свойства

- Оба greedy; корректность из cut property и cycle property (matroid).
- Применение: network design, кластеризация, аппроксимация TSP (см. ../sets/union-find.md).
