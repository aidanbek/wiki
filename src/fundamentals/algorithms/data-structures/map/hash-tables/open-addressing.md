# Open Addressing (Открытая адресация)

При коллизии элемент кладётся в другую свободную ячейку самого массива — без отдельных списков.

## Стратегии пробирования

- **Linear probing** — проверять следующие ячейки подряд (cache-friendly, но primary clustering).
- **Quadratic probing** — шаг растёт квадратично (меньше кластеризации).
- **Double hashing** — шаг задаёт вторая хэш-функция (лучшее распределение).

## Свойства

- Экономит память, cache-friendly; требует load factor < 1 и резко деградирует у заполнения.
- Удаление сложнее: нужны tombstones, чтобы не рвать цепочки поиска (см. chaining.md).
