Hash Table Analysis (Анализ сложности)

Производительность хэш-таблицы определяется load factor и качеством хэш-функции.

## Load factor

- α = n/m (элементов / корзин). Рост α увеличивает коллизии и время операций.
- При превышении порога (напр. 0.75) — resize: массив большего размера + rehash всех элементов (амортизированно O(1) на вставку).

## Сложность

- Average: search/insert/delete — O(1); Worst: O(n) (много коллизий, все ключи в одну корзину).
- Chaining деградирует плавно; open addressing — резко по мере приближения α к 1 (см. collision-resolution.md).
