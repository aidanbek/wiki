# Hash Functions (Хэш-функции)

Функция, отображающая ключ в число фиксированного диапазона — индекс корзины.

## Свойства хорошей хэш-функции

- **Детерминизм** — одинаковый ключ даёт одинаковый хэш.
- **Равномерность** — ключи распределяются по корзинам без перекосов (меньше коллизий).
- **Скорость** вычисления; лавинный эффект — малое изменение ключа сильно меняет хэш.

## На практике

- Индекс корзины обычно `hash(key) mod m`; для строк — polynomial rolling hash; общего назначения — MurmurHash, FNV.
- Криптографические (SHA) для хэш-таблиц избыточны — слишком медленные.
