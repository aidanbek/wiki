Separate Chaining (Метод цепочек)

Каждая корзина хранит список (chain) всех элементов с этим индексом.

## Как работает

- Вставка: вычислить индекс, добавить в список корзины.
- Поиск: вычислить индекс, пройти список, сравнивая ключи.

## Свойства

- Сложность ~O(1 + α), где α — load factor (n/m); при больших α список можно заменить деревом (как в Java HashMap).
- Проще open addressing и работает при α > 1, но тратит память на указатели (см. collision-resolution.md).
