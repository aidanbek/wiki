Shell Sort (Сортировка Шелла)

Обобщение insertion sort: сначала сортируем элементы, отстоящие на большой gap, затем уменьшаем gap — это убирает
инверсии до финального прохода.

## Сложность

- Зависит от gap-последовательности: Worst O(n²) для простых, O(n^1.5) для Knuth `(3^k−1)/2`, O(n log² n) для Sedgewick.
- In-place, unstable, adaptive.

## Как работает

- Сортируем подпоследовательности с шагом gap, уменьшаем gap (обычно gap/2 или хитрее), финал с gap=1 — обычный insertion sort.

## Где уместна

- Быстрее insertion на средних данных (тысячи элементов), уступает quick/merge на больших.
- Проста и не требует рекурсии/доп. памяти — годится для embedded; в production вытеснена quicksort.
