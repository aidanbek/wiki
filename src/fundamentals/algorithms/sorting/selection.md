# Selection Sort (Сортировка выбором)

На каждой итерации находим минимум в неотсортированной части и ставим его на текущую позицию.

## Сложность

- O(n²) во всех случаях — минимум ищется полным проходом всегда. In-place, unstable.
- Плюс: минимум обменов (≤ n−1), полезно когда запись дорогая.

## Как работает

- После i-й итерации первые i элементов стоят на своих местах.
- Можно хранить минимум и его индекс либо сразу переставлять при нарушении порядка.

```php
<?php

/**
 * Worst O(n^2)
 * Average O(n^2)
 * Best O(n^2)
 */
function selectionSort(array $arr): array 
{
    $count = count($arr);
    
    for ($i = 0; $i < $count - 1; $i++) {
        $min = $i;
        
        for ($j = $i + 1; $j < $count; $j++) {
            if ($arr[$j] < $arr[$min]) {
                $min = $j;
            }
        }
        
        if ($min != $i) {
            [$arr[$i], $arr[$min]] = [$arr[$min], $arr[$i]];
        }
    }
    
    return $arr;
}

$array = [3,4,1,2,5,9,6,7,8];
print_r(selectionSort($array));
```
