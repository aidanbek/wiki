# Percentiles

Статистические меры, делящие распределение. Лучше среднего — не искажаются выбросами и отражают реальный опыт
пользователя.

## Что значат

- p50 (медиана) — половина выше, половина ниже; p95 — 95% быстрее; p99/p99.9 — выбросы (tail latency).
- SLO обычно перцентильные: «p99 latency < 100ms».

## Подсчёт

- Сортировка и позиция; для стримов — приближения (t-digest, HdrHistogram).
- Перцентили нельзя усреднять — нужны гистограммы и слияние распределений (Prometheus histograms); см. [tail-latency](../tail-latency/index.md).
