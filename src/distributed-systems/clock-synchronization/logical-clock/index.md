# Logical Clocks (Lamport)

Счётчик, который отражает не реальное время, а порядок событий. Идея Лесли Лэмпорта: чтобы упорядочить события в
распределённой системе, не нужны синхронные часы — достаточно увеличивать счётчик при каждом событии и передавать его в
сообщениях.

## Как работает

- Каждый узел держит локальный счётчик.
- Перед любым локальным событием — `counter++`.
- При отправке сообщения в него кладётся текущее значение счётчика.
- При получении: `counter = max(local, received) + 1`.

## Что гарантирует

- Если событие A повлияло на B (`A → B`), то `clock(A) < clock(B)` — частичный порядок (partial order).
- Обратное неверно: из `clock(A) < clock(B)` не следует, что A причинно предшествует B — они могут быть параллельны (
  concurrent).

## Ограничения и развитие

- Lamport clock не умеет отличать «причинно связаны» от «параллельны» — для этого нужны [[vector-clocks]].
- Не отражает wall-clock time, поэтому бесполезен для TTL и человекочитаемых timestamp (см. [[ntp]]).
- Используется для detecting causality violations и как основа для total order через тай-брейк по id узла.
