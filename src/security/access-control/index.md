# Access Control

Кто и что может делать в системе. Управление тем, какие субъекты (пользователи, сервисы) имеют доступ к каким ресурсам
и операциям — после того как личность подтверждена аутентификацией.

## Модели

- [RBAC](rbac/index.md) — доступ по ролям; роли назначаются пользователям.
- [ABAC](abac/index.md) — доступ по атрибутам (пользователя, ресурса, окружения); более гибко и динамично.
- [Least Privilege](least-privilege/index.md) — выдавать минимум прав, необходимых для задачи.

## Принципы

- Default deny — по умолчанию запрещено, доступ выдаётся явно.
- Separation of duties — ни один человек не контролирует процесс end-to-end.
- Регулярные access reviews и audit logs — кто, к чему и когда обращался.
