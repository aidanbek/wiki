# Encryption

Преобразование данных в нечитаемый вид так, что прочитать их можно только с ключом. Две основные точки защиты — данные
в покое (на диске) и данные в передаче (по сети); и то и другое бесполезно без надёжного управления ключами.

## Разделы

- [At-Rest](at-rest/index.md) — шифрование хранимых данных (БД, диски, бэкапы).
- [In-Transit](in-transit/index.md) — шифрование данных в передаче по сети.
- [Key Management](key-management/index.md) — генерация, хранение, ротация ключей.

## Ключевая мысль

- Шифрование сильно настолько, насколько защищены ключи: зашифрованные данные без ключа бесполезны, но и ключ в открытом
  доступе обнуляет защиту.
- На современных CPU (AES-NI) overhead минимален — нет причины не шифровать.
